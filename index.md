## Punto tres – Hardware, Software y Python

### Hardware
El **hardware** es la parte física del computador, es decir, todos los componentes que
podemos ver y tocar, como el teclado, el mouse, la pantalla y la CPU.  
Cuando una persona escribe un documento, el teclado funciona como dispositivo de entrada,
la CPU procesa la información, la memoria la almacena y la pantalla muestra el resultado.

### Software
El **software** es el conjunto de programas e instrucciones que le indican al hardware
qué hacer. La conexión entre el software y el hardware es fundamental para que el computador
funcione correctamente y se realiza a través del sistema operativo y los controladores
(drivers).

### Lenguajes de Programación
Los **lenguajes de programación** son un medio de comunicación entre el ser humano y el
computador. Permiten dar instrucciones claras al hardware por medio del software, usando
palabras, símbolos y reglas fáciles de entender para los programadores.
