💻 El Hardware
El hardware es la parte física del computador; es decir, todos los componentes que se pueden ver y tocar.

Ejemplo: Cuando escribes un documento:

Usas el teclado (entrada) para escribir.
La CPU (procesamiento) interpreta cada letra.
El texto se guarda en la RAM o en el disco (almacenamiento).
Finalmente, lo ves en la pantalla (salida).
🧠 El Software
La conexión entre el software y el hardware es fundamental para que un computador funcione correctamente.

El hardware es el cuerpo (componentes físicos).
El software es el cerebro (instrucciones que indican qué hacer).
La comunicación entre ambos se realiza a través del sistema operativo y los controladores (drivers).

🧩 Lenguajes de Programación
Los lenguajes de programación son un medio de comunicación entre el ser humano y el computador.

Permiten dar instrucciones precisas al hardware a través del software. En lugar de usar lenguaje binario (ceros y unos), utilizan palabras, símbolos y reglas que los programadores pueden entender fácilmente.

🐍 Python
Python es un lenguaje de programación sencillo y fácil de aprender.

📌 Ejemplo
nombre = input("¿Cómo te llamas? ")
print("¡Hola, " + nombre + "! Bienvenido a Python")
📝 Explicación paso a paso
input("¿Cómo te llamas? "): muestra un mensaje y espera que el usuario escriba su nombre.
El valor ingresado se guarda en la variable nombre.
print(...): muestra en pantalla un saludo usando el nombre ingresado.
📦 Variables, Valores y Operadores en Python
¿Qué es una variable?
Una variable es un espacio en la memoria del computador donde se guarda un valor.

¿Qué es un valor?
Un valor es la información almacenada en una variable. Puede ser de diferentes tipos:

Texto (str)
Número entero (int)
Número decimal (float)
Lógico (bool)
➕ Operadores en Python
Los operadores permiten realizar operaciones con los valores de las variables.

Operadores aritméticos
+   Suma
-   Resta
*   Multiplicación
/   División
//  División entera
%   Módulo
**  Potencia
🔢 Orden de las Operaciones en Python
Cuando una expresión tiene varias operaciones, Python sigue un orden de prioridad, conocido como precedencia de operadores:

Paréntesis ( )
Potencias **
Multiplicación, División, División entera y Módulo *, /, //, %
Suma y Resta + , -
🔤 Operaciones con Cadenas de Texto
Una cadena de texto (string) es una secuencia de caracteres entre comillas simples ' ' o dobles " ".

Ejemplo
mensaje = "Hola"
nombre = 'Lina'
⌨️ Lectura y Escritura de Valores
En Python podemos:

Leer datos del usuario con input()
Mostrar resultados en pantalla con print()
🌍 Alcance de las Variables: Globales y Locales
El alcance de una variable indica en qué parte del programa puede utilizarse.

Variables globales
Se declaran fuera de las funciones.
Pueden usarse en cualquier parte del programa.
Variables locales
Se declaran dentro de una función.
Solo existen mientras la función se ejecuta.
🔀 Condicionales: if, elif y else
Los condicionales permiten que el programa tome decisiones según si una condición es verdadera o falsa.

if condicion:
    # Código si la condición es verdadera
elif otra_condicion:
    # Código si la anterior fue falsa y esta verdadera
else:
    # Código si ninguna condición fue verdadera
✍️ Reflexión
El hardware, el software y los lenguajes de programación trabajan juntos para que un computador funcione correctamente.

Aprender Python permite comprender mejor esta conexión, ya que mediante variables, operadores y condicionales podemos dar instrucciones que el computador ejecuta paso a paso. Conocer estos conceptos nos ayuda a entender cómo funciona la tecnología y a crear nuestras propias soluciones.
