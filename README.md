**PUNTO TRES**

**El Hardware** : es la parte física del computador: todos los componentes que puedes ver y tocar. Ejemplo Cuando escribes un documento: Usas el teclado (entrada) para escribir, la CPU (procesamiento) interpreta cada letra, el texto se guarda en la RAM o el disco (almacenamiento), Lo ves en la pantalla (salida).

**Software** : La conexión entre el software y el hardware es fundamental para que un computador funcione. El hardware es el cuerpo (los componentes físicos).El software es el cerebro (las instrucciones que le dicen al hardware qué hacer). ¿Cómo se conectan? La comunicación entre el software y el hardware se da a través del sistema operativo y los controladores (drivers).

**Los Lenguajes de Programación** es un medio de comunicación entre el ser humano y el computador.
Permite darle instrucciones precisas al hardware a través del software. En lugar de usar el lenguaje binario (hecho de ceros y unos), los lenguajes de programación usan palabras, símbolos y reglas que los programadores entienden con facilidad

**Python** ejemplo # Este programa pide tu nombre y te saluda nombre = input("¿Cómo te llamas? ")
print("¡Hola, " + nombre + "! Bienvenido a Python")

**Variables, Valores y Operadores en Python**

**¿Qué es una variable?**: una **variable** es un espacio en la memoria del computador donde se **guarda un valor**.  

**¿Qué es un valor?**: Un valor es la información real que se almacena en la variable.
Puede ser de distintos tipos: Texto (str), Número entero (int), Número decimal (float), Lógico (bool)

**Operadores en Python**:Los operadores permiten realizar operaciones con los valores de las variables. **Operadores aritméticos**: +,-,*,/,//,%,**.

**Orden de las Operaciones en Python**: Cuando una expresión tiene **varias operaciones**, Python sigue un **orden de prioridad** para decidir **qué calcular primero**.  
Este orden se llama **precedencia de operadores, 
Paréntesis ( ), Potencias **,Multiplicación, División, División entera y Módulo *, /, //, %,Suma y Resta +, -

**Operaciones con Cadenas de Texto en Python**:Una **cadena de texto** (o *string*) es una **secuencia de caracteres** entre comillas simples `' '` o dobles `" "`.
Ejemplo:
python mensaje = "Hola"
nombre = 'Lina'

**Lectura y Escritura de Valores en Variables**: En Python, podemos **leer datos** (recibir información del usuario) y **escribir datos** (mostrar resultados en pantalla).  
Estas dos acciones se realizan con las funciones **`input()`** y **`print()`**.

**Alcance de las Variables: Globales y Locales enen python**:el **alcance de una variable** indica **en qué parte del programa se puede usar**.  
Existen dos tipos principales de variables según su alcance
**Variables Globales**: se **declara fuera de las funciones** y puede **usarse en cualquier parte del programa**, incluso dentro de funciones (si solo se consulta su valor).
**Variables Locales**:se declara dentro de una función y solo existe mientras la función se ejecuta.
No puede usarse fuera de esa función.

**Condicionales: if, elif y else**: Los condicionales permiten que el programa **elegir qué hacer** según si una condición es **verdadera o falsa**.
